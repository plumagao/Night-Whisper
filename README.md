# Night Whisper 星空聚会 / Star Party

Official bilingual website for **Night Whisper 星空聚会 2026**.

- 日期 / Date: 2026.11.06–11.08
- 地点 / Venue: 红柯窑 · 安徽黄山 / Hongkeyao · Huangshan, Anhui
- 域名 / Domain: nightwhisper.cc

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Deployment

1. Push this repository to GitHub
2. Import the repository into Vercel
3. Deploy with default settings
4. Add `nightwhisper.cc` as a custom domain after testing
